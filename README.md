# Fairness and Refusal Behavior of LLMs in Credit Scoring

Code for the Bachelor's thesis "LLM Behavior in Credit Scoring"

## Abstract

This thesis investigates fairness and refusal behavior of Large Language Models (LLMs) in credit scoring contexts using correspondence testing methodology. We evaluate three models (GPT OSS 120B, Qwen3 235B Thinking, Qwen3 Coder 30B) on 100 profiles from the German Credit Dataset.

**Research Questions:**
1. Do LLM-generated credit scores vary when only gender is changed?
2. Do LLMs demonstrate pushback when asked to score profiles with protected attributes?
